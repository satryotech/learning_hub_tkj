Modul 01

Teknik Komputer: Hardware

Memahami bagian fisik komputer, fungsi, karakteristik, dan cara perawatan dasarnya.

HARDWARE

Kenali komputer dari komponen fisiknya.

Hardware adalah bagian fisik yang dapat dilihat atau disentuh. Setiap komponen bekerja bersama untuk menerima input, memproses data, menyimpan data, dan menghasilkan output.

1. Pengertian Hardware

Hardware atau perangkat keras adalah seluruh komponen fisik pada sistem komputer. Hardware tidak dapat menjalankan tugas secara mandiri tanpa software yang memberikan instruksi.

Dalam konsep sederhana, komputer menerima input, melakukan process, menyimpan data bila diperlukan, lalu menghasilkan output.

Ingat: hardware = benda fisik; software = kumpulan instruksi/program yang dijalankan oleh komputer.

2. Motherboard

Motherboard adalah papan sirkuit utama yang menjadi tempat berbagai komponen penting terhubung dan berkomunikasi.

  • Menjadi tempat pemasangan CPU dan RAM.
  • Menyediakan slot ekspansi seperti PCI Express.
  • Menyediakan konektor storage, USB, audio, jaringan, dan power.
  • Mengatur jalur komunikasi antarkomponen melalui chipset dan controller.
BagianFungsi
CPU SocketTempat memasang processor yang kompatibel.
DIMM SlotTempat memasang modul RAM.
PCIe SlotUntuk perangkat ekspansi seperti GPU atau kartu tambahan.
SATA / M.2Antarmuka untuk perangkat penyimpanan tertentu.

3. CPU / Processor

CPU atau Central Processing Unit menjalankan instruksi dan melakukan operasi logika maupun aritmetika. CPU sering disebut sebagai salah satu pusat pemrosesan komputer.

  • Core: unit pemrosesan di dalam processor.
  • Clock speed: frekuensi kerja yang umumnya dinyatakan dalam GHz.
  • Cache: memori berkecepatan tinggi untuk data/instruksi yang sering digunakan.
  • Instruction set: kumpulan instruksi yang dapat dipahami oleh processor.

4. RAM

RAM atau Random Access Memory adalah memori kerja sementara yang digunakan sistem untuk menyimpan data dan instruksi yang sedang aktif.

RAM bersifat volatile, sehingga data di dalamnya hilang ketika daya listrik terputus. Kapasitas RAM yang lebih besar dapat membantu menjalankan lebih banyak aplikasi secara bersamaan, tetapi performa juga dipengaruhi oleh processor, storage, dan software.

5. Storage: HDD dan SSD

Storage digunakan untuk menyimpan sistem operasi, aplikasi, dan file secara relatif permanen.

AspekHDDSSD
TeknologiPiringan magnetik dan head mekanis.Memori flash tanpa bagian mekanis bergerak.
KecepatanUmumnya lebih rendah.Umumnya lebih tinggi.
Ketahanan guncanganLebih sensitif terhadap benturan saat bekerja.Lebih tahan terhadap guncangan mekanis.
Contoh penggunaanArsip berkapasitas besar.OS, aplikasi, laptop, dan workstation.

6. GPU & Display

GPU atau Graphics Processing Unit menangani pemrosesan grafis. GPU dapat terintegrasi dengan processor atau berupa kartu grafis terpisah.

  • Menampilkan antarmuka desktop dan aplikasi.
  • Mendukung pengolahan grafis 2D/3D.
  • Dapat digunakan untuk pekerjaan komputasi paralel tertentu.
  • Terhubung ke monitor melalui antarmuka display yang sesuai.

7. PSU

Power Supply Unit mengubah dan menyalurkan daya listrik sesuai kebutuhan komponen komputer. PSU yang sesuai harus memiliki daya cukup dan konektor yang kompatibel.

Praktik aman: jangan membuka PSU yang masih tersambung listrik. Untuk pemeriksaan internal, ikuti prosedur keselamatan dan lakukan dengan pengawasan yang kompeten.

8. Perangkat Input dan Output

Perangkat input memasukkan data atau perintah, sedangkan perangkat output menyajikan hasil pemrosesan.

JenisContohFungsi
InputKeyboard, mouse, scanner, microphone.Memasukkan data/perintah.
OutputMonitor, printer, speaker.Menyajikan hasil pemrosesan.
Input/OutputTouchscreen, storage eksternal.Dapat menerima dan/atau mengirim data.

9. Perawatan Hardware

  1. Matikan perangkat sesuai prosedur sebelum membersihkan bagian internal.
  2. Jaga ventilasi dan hindari penumpukan debu berlebihan.
  3. Gunakan kabel dan adaptor yang sesuai spesifikasi.
  4. Hindari cairan masuk ke perangkat.
  5. Lakukan backup data sebelum pekerjaan berisiko terhadap penyimpanan.
  6. Catat perubahan komponen agar troubleshooting berikutnya lebih mudah.

Modul 02 & 03

Software & Sistem Operasi

Memahami jenis software dan bagaimana sistem operasi mengelola hardware serta aplikasi.

1. Pengertian Software

Software adalah kumpulan instruksi, program, konfigurasi, dan data yang membuat komputer melakukan tugas tertentu.

Jenis software

  • System software: sistem operasi dan komponen pendukung sistem.
  • Application software: browser, editor, office, multimedia, dan aplikasi produktivitas.
  • Utility: alat pemeliharaan seperti backup, disk management, dan monitoring.
  • Development tools: compiler, interpreter, editor, debugger, dan IDE.

2. Sistem Operasi

Sistem operasi menjadi penghubung antara pengguna, aplikasi, dan hardware. OS mengelola sumber daya serta menyediakan layanan dasar bagi aplikasi.

  • Manajemen proses dan thread.
  • Manajemen memori.
  • Manajemen file dan storage.
  • Manajemen device dan driver.
  • User account dan permission.
  • Networking dan service.

3. Booting

Booting adalah proses ketika komputer mulai berjalan dan mempersiapkan sistem operasi untuk digunakan.

  1. Power on atau reset.
  2. Firmware melakukan inisialisasi hardware.
  3. Perangkat boot dipilih sesuai konfigurasi.
  4. Bootloader dimuat.
  5. Kernel sistem operasi dijalankan.
  6. Service dan antarmuka pengguna dipersiapkan.

4. Driver

Driver adalah software yang membantu sistem operasi berkomunikasi dengan hardware tertentu. Contohnya driver jaringan, audio, graphics, dan printer.

Tips troubleshooting: jika perangkat tidak bekerja normal, periksa koneksi fisik, status device, driver, dan pengaturan sistem sebelum mengganti komponen.

5. File System

File system mengatur bagaimana file dan folder disimpan serta ditemukan pada media penyimpanan.

KonsepPenjelasan
FileKumpulan data yang diberi nama dan metadata.
Folder/DirectoryStruktur untuk mengelompokkan file dan folder lain.
PathLokasi file atau folder dalam struktur penyimpanan.
PermissionAturan yang menentukan siapa yang boleh melakukan tindakan tertentu.

6. Maintenance Software

  • Lakukan update sistem dan aplikasi dari sumber tepercaya.
  • Hapus aplikasi yang tidak diperlukan.
  • Kelola ruang penyimpanan.
  • Gunakan backup untuk file penting.
  • Gunakan proteksi keamanan dan lakukan pemindaian sesuai kebutuhan.
  • Dokumentasikan error dan perubahan konfigurasi.

Contoh perintah dasar jaringan pada terminal

Perintah dapat berbeda tergantung sistem operasi. Gunakan sesuai kebutuhan dan pahami hasilnya sebelum menjalankan perintah administrasi.

ipconfig ipconfig /all ping 8.8.8.8 tracert example.com nslookup example.com

Modul 04

Networking Dasar

Fondasi jaringan komputer untuk memahami konektivitas, perangkat, alamat, dan troubleshooting.

1. Apa itu jaringan komputer?

Jaringan komputer adalah sekumpulan perangkat yang saling terhubung agar dapat bertukar data dan menggunakan sumber daya tertentu.

  • LAN: jaringan area lokal seperti lab sekolah.
  • WAN: jaringan yang mencakup area geografis lebih luas.
  • Internet: jaringan global yang menghubungkan banyak jaringan.

2. Perangkat jaringan

  • Switch: menghubungkan perangkat dalam jaringan lokal.
  • Router: menghubungkan jaringan berbeda dan menentukan rute paket.
  • Access Point: menyediakan konektivitas wireless ke jaringan.
  • Modem/ONT: menjadi bagian dari akses ke jaringan provider sesuai teknologi layanan.
  • NIC: antarmuka jaringan pada komputer atau perangkat.

3. IP Address

IP address adalah alamat logis yang digunakan untuk mengidentifikasi interface/perangkat pada jaringan IP.

Contoh IPv4: 192.168.1.10. IPv4 menggunakan 32 bit dan biasanya ditulis dalam empat kelompok angka desimal.

IstilahMakna
IP addressAlamat logis pada jaringan IP.
Subnet maskMembantu menentukan bagian network dan host pada IPv4.
GatewayAlamat perangkat yang digunakan sebagai jalur menuju jaringan lain.
DNSLayanan yang menerjemahkan nama domain menjadi alamat IP dan sebaliknya sesuai jenis record.

4. MAC Address

MAC address adalah alamat pada interface jaringan yang berada pada lapisan data link. Format penulisannya biasanya berupa kelompok nilai heksadesimal.

MAC address sering digunakan dalam proses komunikasi jaringan lokal dan dapat terlihat pada informasi adapter jaringan.

5. Topologi jaringan

  • Star: perangkat terhubung ke perangkat pusat seperti switch.
  • Bus: perangkat berbagi jalur utama.
  • Ring: perangkat tersusun membentuk lingkaran.
  • Mesh: memiliki banyak koneksi antarnode untuk redundansi.
  • Hybrid: gabungan lebih dari satu bentuk topologi.

6. Troubleshooting jaringan

  1. Pastikan kabel, konektor, dan link indicator dalam kondisi baik.
  2. Periksa status adapter jaringan.
  3. Periksa konfigurasi IP.
  4. Uji konektivitas dengan ping secara bertahap.
  5. Periksa gateway dan DNS bila koneksi ke internet bermasalah.
  6. Dokumentasikan hasil pengujian agar masalah mudah dilacak.
